# Security

## Verify your download

Compare the SHA256 hash in the release notes with your file:

```
certutil -hashfile "NetRouter Setup 1.3.0.exe" SHA256
```

Only download NetRouter from this repository's **Releases** page.

## Reporting a vulnerability

Please do not post security problems in public issues. Use **Security → Report a vulnerability** on this repository (private vulnerability reporting) and describe what you found and how to reproduce it.
