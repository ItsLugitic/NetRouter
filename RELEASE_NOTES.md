## NetRouter 1.3.0

**English:** Choose which internet connection each Windows program uses. This release adds an English/Persian interface, a built-in guide, and a faster, smarter "Route by destination" mode.

**فارسی:** انتخاب کن هر برنامه‌ی ویندوز از کدام اینترنت استفاده کند. این نسخه رابط فارسی و انگلیسی، راهنمای داخل برنامه و «مسیر مقصد» سریع‌تر و هوشمندتر دارد.

### Install / نصب
1. Download **NetRouter.Setup.1.3.0.exe** below (Assets). / فایل نصبی را از بخش Assets پایین همین صفحه دانلود کن.
2. SmartScreen warning? Click **More info → Run anyway** (the installer is not code-signed). / اگر هشدار SmartScreen آمد، روی More info و بعد Run anyway بزن.
3. Open NetRouter and press **Install automatically** for ForceBindIP. / برنامه را باز کن و دکمه‌ی نصب خودکار را بزن.

Requires Windows 10/11 (64-bit) and two active connections. Read the [guide](https://github.com/ItsLugitic/NetRouter/blob/main/docs/GUIDE.md) if a program does not follow your choice.
