# راهنمای NetRouter

[English](GUIDE.md) · [بازگشت به README](../README.fa.md)

همه‌ی چیزهایی که برای استفاده و رفع مشکل لازمه، اینجاست. اگه برنامه‌ای روی اینترنت دلخواه نمیره، از بخش ۴ شروع کن.

## ۱. شروع سریع

1. اگه نوار نارنجی «ForceBindIP نصب نیست» بالای صفحه هست، دکمه‌ی **نصب خودکار** رو بزن.
2. تو تب **در حال اجرا** برنامه‌ی مورد نظرت رو پیدا کن. اگه هنوز باز نیست، فایل exe اش رو تو «برنامه‌های من» بکش و رها کن.
3. تو منوی کشویی کنارش اینترنت دلخواه رو انتخاب کن و **انتقال** (یا ▶ اجرا) رو بزن.
4. بعد از چند ثانیه NetRouter نتیجه رو بررسی میکنه و میگه «تأیید شد» یا هشدار میده که برنامه هنوز روی اینترنت قبلیه.

## ۲. بهترین روش استفاده (مخصوص گیمرها)

اینترنت اصلی و سریع‌ات (مثلاً فیبر) رو پیش‌فرض ویندوز نگه دار. بازی‌ها بدون هیچ تغییری از همون میرن. فقط برنامه‌های پس‌زمینه مثل استیم، لانچر بازی‌ها و دانلودرها رو به اینترنت دوم (مثلاً ADSL یا وایفای) ببر تا وسط بازی پینگ بالا نره.


اگه استیم رو منتقل میکنی، قبل از شروع بازی انجامش بده. بازی‌ای که استیم باز میکنه روی اینترنت پیش‌فرض میمونه و از انتقال تأثیر نمیگیره.

## ۳. «انتقال» یا «مسیر مقصد»؟

**انتقال:** برنامه رو میبنده و با ابزار ForceBindIP دوباره روی اینترنت انتخابی اجرا میکنه. ادمین نمیخواد، ولی روی برنامه‌هایی که شبکه رو تو پروسه‌ی فرعی انجام میدن جواب نمیده.


**🧭 مسیر مقصد:** برنامه ریستارت نمیشه. NetRouter آدرس سرورهایی که برنامه بهشون وصله رو پیدا میکنه و فقط همون‌ها رو از اینترنت انتخابی میفرسته. روی لانچرها و برنامه‌های چندپروسه‌ای جواب میده. ادمین میخواد.

## ۴. اینترنت عوض میشه ولی برنامه هنوز روی اینترنت قبلیه

1. NetRouter رو با ادمین باز کن و تو تب **تشخیص مشکل** گزینه‌ی «اجرای تشخیص» رو بزن.
2. اگه **آی‌پی عمومی هر دو اینترنت یکسان** بود: یا دو مودم هم‌رنج هستن (بخش ۶)، یا هر دو واقعاً یک خط هستن، یا Weak Host روشنه (بخش ۱۱).
3. اگه **آی‌پی‌ها فرق داشت**: ویندوز درست کار میکنه و مشکل از خود برنامه‌ست. بخش ۵ (مسیر مقصد) رو انجام بده.
4. اگه تشخیص گفت **پروکسی یا VPN روشنه**: بخش ۸ رو بخون.

## ۵. مسیر مقصد (راهنمای کامل)

1. NetRouter رو با «اجرا با دسترسی ادمین» باز کن.
2. برنامه رو اجرا کن و دانلود یا کارش رو شروع کن تا اتصال داشته باشه.
3. تو تب «در حال اجرا»، ردیف‌هایی که اتصال زیاد دارن بالای لیست هستن. اینترنت دلخواه رو انتخاب کن و روی **🧭 مسیر مقصد** بزن. اگه چند برنامه‌ی مرتبط اتصال دارن (مثلاً لانچر و دانلودرش)، برای هر کدوم بزن.
4. دانلود رو یک بار **Pause و Resume** کن تا اتصال‌های تازه از اینترنت جدید ساخته بشن.
5. سرعت اینترنت‌ها بالای صفحه باید جابجا بشه.


**چرا گاهی یک لحظه روی اینترنت قبلی برمیگرده؟** برنامه‌ها گاهی به آدرس‌های تازه‌ی سرور وصل میشن و NetRouter باید اول اون آدرس رو ببینه تا براش مسیر بسازه. اتصال اول ممکنه یک لحظه از اینترنت قبلی شروع بشه یا قطع و وصل بشه. NetRouter آدرس‌هایی که دیده رو یادش میمونه و دفعه‌ی بعد از همون ابتدا مسیر میده، پس بعد از چند دقیقه یا بار دوم، این اتفاق خیلی کمتر میشه.


**محدودیت‌ها:** فقط IPv4 و TCP رو پوشش میده (UDP و QUIC نه). مسیرها با بستن NetRouter پاک میشن. برای پاک کردن همه‌ی قانون‌ها: تنظیمات، «پاک کردن همه». مسیر برای همه‌ی برنامه‌هایی که به همون آدرس وصل بشن اعمال میشه.

## ۶. دو مودم هم‌رنج (خیلی شایع)

خیلی از مودم‌ها آدرس 192.168.1.1 دارن. اگه مودم ADSL و مودم فیبر هر دو همین آدرس رو داشته باشن، ویندوز بین دو کارت گیج میشه و هیچ ابزاری درست کار نمیکنه. تو تب تشخیص، هشدار «هم‌رنج» میبینی.


**راه‌حل:** وارد پنل یکی از مودم‌ها شو (معمولاً 192.168.1.1 تو مرورگر)، تو بخش LAN یا DHCP آدرس مودم رو به 192.168.2.1 تغییر بده و ذخیره کن. بعد مودم رو ریستارت کن و دوباره وصل شو.

## ۷. خطای Error 740 و دسترسی ادمین

این خطا یعنی برنامه‌ی هدف خودش دسترسی ادمین میخواد. NetRouter رو با دکمه‌ی «🛡 اجرا با دسترسی ادمین» (منوی کناری) دوباره باز کن. حالت ادمین برای «مسیر مقصد» و بستن برنامه‌هایی که با ادمین اجرا شدن هم لازمه.


تو حالت ادمین، کشیدن و رها کردن فایل از اکسپلورر کار نمیکنه (محدودیت ویندوز). با کلیک روی کادر «افزودن»، فایل رو انتخاب کن. اجرا همراه ویندوز هم خودکار با ادمین نیست.

## ۸. پروکسی و VPN (V2Ray، Clash و مشابه)

وقتی پروکسی یا VPN روشنه، ترافیک برنامه‌ها اول وارد اون میشه و بعد خود برنامه‌ی VPN با اینترنت پیش‌فرض بیرون میره. تو این حالت انتخاب اینترنت برای برنامه‌ها اثری نداره، چون اتصال از طرف برنامه‌ی VPN ساخته میشه، نه خود برنامه.


برای تست، VPN و پروکسی سیستم رو خاموش کن. اگه لازمت هست، تو خود برنامه‌ی VPN اینترنت خروجی رو انتخاب کن. Tailscale معمولاً مشکلی ایجاد نمیکنه.

## ۹. بازی‌های دارای آنتی‌چیت

بازی‌هایی مثل Valorant، یا هر بازی با Easy Anti-Cheat، BattlEye و مشابه رو با «انتقال» یا «اجرا» اجرا نکن. تزریق DLL ممکنه به اشتباه تقلب حساب بشه و باعث بن بشه. بازی رو دست نخورده روی اینترنت پیش‌فرض بذار و فقط لانچر و دانلودر رو منتقل کن. مسیر مقصد تزریق نداره، ولی همچنان بهتره روی خود بازی استفاده نشه. مسئولیت استفاده با خودته.

## ۱۰. مرورگرها

مرورگرهای کرومیومی (Chrome، Edge، Brave و مشابه) شبکه رو تو یک پروسه‌ی جدا اجرا میکنن، پس «انتقال» روشون جواب نمیده. «مسیر مقصد» ممکنه جواب بده، ولی برای بیشتر کاربرها لازم نیست.

## ۱۱. Weak Host

اگه تشخیص گفت Weak Host روشنه، تو CMD با ادمین این دستور رو برای هر دو کارت بزن (اسم کارت رو با اسمی که تو NetRouter میبینی عوض کن):


```
netsh interface ipv4 set interface "Wi-Fi" weakhostsend=disabled weakhostreceive=disabled
```

## ۱۲. هشدار SmartScreen و آنتی‌ویروس

فایل نصبی امضای دیجیتال نداره، پس ویندوز موقع نصب هشدار میده. روی **More info** و بعد **Run anyway** بزن. بعضی آنتی‌ویروس‌ها هم ممکنه به خاطر اجرای PowerShell و ابزار تزریق اخطار اشتباه بدن.

## ۱۳. HUD روی بازی دیده نمیشه

HUD روی بازی‌هایی که تمام‌صفحه‌ی واقعی (Exclusive Fullscreen) هستن دیده نمیشه. تو تنظیمات بازی حالت **Borderless Windowed** رو انتخاب کن.

## ۱۴. سوال‌های پرتکرار

**DNS از کدوم اینترنت میره؟** همیشه از اینترنت پیش‌فرض ویندوز.


**هر بار باید برنامه رو از NetRouter اجرا کنم؟** برای «انتقال/اجرا» بله. برنامه رو تو «برنامه‌های من» ذخیره کن و ▶ رو بزن. «مسیر مقصد» بعد از تنظیم، هر بار که برنامه باز بشه خودش کار میکنه (تا وقتی NetRouter با ادمین باز باشه).


**بعد از ریستارت ویندوز؟** مسیرهای مقصد پاک میشن و با اجرای دوباره‌ی NetRouter و باز شدن برنامه، خودکار ساخته میشن. اجرا همراه ویندوز رو میتونی تو تنظیمات روشن کنی.
