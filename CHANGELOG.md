# Changelog

## 1.3.0
- English and Persian interface, switchable in Settings.
- New **Guide** tab with step-by-step fixes (also in `docs/`).
- Route by destination is faster and proactive: it now sees connections while they are still opening and remembers the server addresses a program used before, so a program rarely slips back to the old connection.

## 1.2.1
- New **Diagnose** tab: public IP per connection, same-subnet modems, proxy or VPN, Weak Host and gateway checks, with a copyable report.

## 1.2.0
- New **🧭 Route by destination** mode for launchers that download in a separate process. Needs administrator.

## 1.1.2
- After every Move or Run, NetRouter now verifies that the program really uses the chosen connection and reports the result.

## 1.1.1
- "Run as administrator" button, for programs that fail with Error 740.

## 1.1.0
- Running programs scan, My programs, floating HUD, tray icon, start with Windows, one-click ForceBindIP install.

## 1.0.0
- First version.
